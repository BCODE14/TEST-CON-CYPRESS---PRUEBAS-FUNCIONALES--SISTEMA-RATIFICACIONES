# TEST-CON-CYPRESS PRUEBAS FUNCIONALES SISTEMA RATIFICACIONES
Construí una serie de scripts automatizados con Cypress para realizar pruebas funcionales sobre un sistema de ratificaciones.
En el desarrollo de estas pruebas utilicé funciones personalizadas que facilitaron la reutilización de código y mejoraron la mantenibilidad del proyecto.

Además, la configuración implementada permite capturar evidencias en imágenes y videos de cada ejecución, lo que garantiza un mejor seguimiento, análisis de resultados y documentación de los casos de prueba.
